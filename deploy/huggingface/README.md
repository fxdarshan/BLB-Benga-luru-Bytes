# BLB API

The backend of [Banga-Luru Bytes](https://blb-frontend.vercel.app), restaurant recommendations for Bangalore, ranked and explained by AI. The web page calls this API; it has no page of its own. `GET /health` says whether it is up.

This Space is deployed automatically from [github.com/fxdarshan/BLB-Benga-luru-Bytes](https://github.com/fxdarshan/BLB-Benga-luru-Bytes) by its "Deploy to Hugging Face" workflow. Change the code there, not here: each deploy replaces these files.
